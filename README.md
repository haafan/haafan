## 🚀 Featured projects

### 🎙️ QueryVoice: Voice-Driven Business Intelligence
Ask a question out loud, get SQL and a chart back.

- Speech-to-text with **Whisper**, orchestration with **LangGraph**, served via **FastAPI**
- **Qwen2.5-Coder-7B** fine-tuned with **QLoRA** for text-to-SQL
- **RAG** over the database schema (ChromaDB), a **self-correcting query loop**, SQL safety guardrails and a **semantic cache**

`Python` `Whisper` `Qwen2.5` `LangGraph` `FastAPI` `ChromaDB` `QLoRA`

### ❤️ ECG Anomaly Detection
A CNN autoencoder trained on the PTB-DB dataset that flags abnormal heartbeats by reconstruction error, served through an API and a simple web page.

`Python` `Deep Learning` `CNN Autoencoder`

### 📊 Web Usage Mining with MLOps
Browsing-pattern discovery on NASA server logs using **Apriori, FP-Growth and ECLAT**, wrapped in a full MLOps workflow: data versioning, experiment tracking, model registry, monitoring, and a **Streamlit** dashboard.

`Python` `Weights & Biases` `Streamlit` `Association Rules`

### 🚗 AutoMate
Driving school management software: helps license candidates prepare for the exam and gives school owners tools to manage their school, candidates and activity.
